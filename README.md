# 🩺 Multi-Disease Risk Intelligence System with Explainable AI

An AI-powered healthcare web application that predicts the risk of multiple chronic diseases using routine clinical parameters and provides transparent explanations through Explainable AI (XAI). The system promotes preventive healthcare by helping users understand potential health risks through interactive visualizations and personalized recommendations.

---

# 📌 Overview

The **Multi-Disease Risk Intelligence System** is an AI-driven healthcare platform that analyzes routine health parameters to estimate the risk of:

- 🩸 Diabetes
- ❤️ Heart Disease
- 🩺 Chronic Kidney Disease
- 🩸 Anemia

Unlike conventional prediction systems, this project also provides **Explainable AI (XAI)** insights, helping users understand why a particular prediction was made.
